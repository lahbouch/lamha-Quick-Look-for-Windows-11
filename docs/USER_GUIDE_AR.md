# دليل استخدام لمحة

**لمحة** أداة لنظام Windows تعرض محتوى الملفات فورًا دون فتح البرنامج الأصلي. حدد ملفًا في مستكشف الملفات، واضغط مفتاح المسافة، واقرأه مباشرة.

## التثبيت

1. شغّل الملف `Lamha-Setup-1.0.0.exe`.
2. اتبع الخطوات. لا يحتاج التثبيت إلى صلاحيات المسؤول، ولا إلى Microsoft Office أو أي برنامج آخر.
3. يبدأ التطبيق في الخلفية، وتظهر أيقونته في منطقة الإعلام بجوار الساعة.

## طريقة الاستخدام

1. افتح مستكشف الملفات وحدد ملفًا واحدًا أو عدة ملفات.
2. اضغط **مسافة**. تظهر نافذة المعاينة في منتصف الشاشة.
3. اضغط **مسافة** مرة أخرى للإغلاق، وستعود إلى المستكشف حيث كنت.

## اختصارات لوحة المفاتيح

| المفتاح | الوظيفة |
|---|---|
| مسافة | فتح المعاينة أو إغلاقها |
| Esc | إغلاق المعاينة |
| F1 | عرض قائمة الاختصارات |
| F | فتح المجلد الذي يحتوي الملف |
| F11 | ملء الشاشة |
| السهم الأيسر | الملف السابق |
| السهم الأيمن | الملف التالي |
| Enter | فتح الملف الأصلي |
| Ctrl + C | نسخ النص المحدد، أو نسخ الملف إذا لم يكن هناك نص محدد |
| Ctrl + F | البحث داخل مستندات PDF وOffice |
| F3 أو Shift + F3 | نتيجة البحث التالية أو السابقة |
| + أو - | تكبير أو تصغير |
| 0 | ملاءمة النافذة أو الصفحة |
| 1 | الحجم الفعلي |
| 2 | ملاءمة العرض |
| R أو Shift + R | تدوير الصورة في اتجاه عقارب الساعة أو عكسه |
| Page Up أو Page Down | الصفحة أو الشريحة أو ورقة Excel السابقة أو التالية |
| Home أو End | أول صفحة أو آخر صفحة |
| T | إظهار المصغرات أو إخفاؤها |
| Ctrl + P | طباعة |
| W | التفاف الأسطر في الملفات النصية |
| P | تشغيل الفيديو أو الصوت أو إيقافه |
| J أو L | إرجاع أو تقديم 5 ثوانٍ |
| السهمان لأعلى ولأسفل | مستوى الصوت أثناء تشغيل الوسائط |
| M | كتم الصوت |
| Ctrl + عجلة الفأرة | تكبير أو تصغير |
| عجلة الفأرة | التمرير |
| النقر المزدوج | فتح الملف الأصلي |

يؤدي النقر خارج نافذة المعاينة، مثل النقر على ملف في المستكشف، إلى إغلاقها.

## الملفات المدعومة

| النوع | الامتدادات |
|---|---|
| الصور | PNG، JPG، JPEG، WEBP، GIF، BMP، TIFF، SVG |
| المستندات | PDF |
| Word | DOCX، DOC |
| Excel | XLSX، XLS |
| PowerPoint | PPTX، PPT |
| النصوص | TXT، MD، CSV، JSON، XML، HTML |
| الوسائط | MP4، MP3 |

تستغرق معاينة مستندات Office ثانيتين تقريبًا في المرة الأولى، ثم تفتح فورًا لأن نسخة العرض تُحفظ مؤقتًا على جهازك.

## الإعدادات

انقر أيقونة لمحة بجوار الساعة بالزر الأيسر لفتح الإعدادات، أو بالزر الأيمن لعرض القائمة.

- **التشغيل مع بدء Windows:** يبدأ التطبيق تلقائيًا عند تسجيل الدخول.
- **التكامل مع المستكشف:** عند إيقافه، يعود مفتاح المسافة إلى سلوكه المعتاد في المستكشف.
- **تحديث المعاينة تلقائيًا:** عند تفعيله، تبقى المعاينة مفتوحة عند النقر في المستكشف وتتبع الملف المحدد بدلًا من أن تُغلق.
- **حجم النافذة:** يتكيف مع المحتوى، أو كبير دائمًا.
- **التكبير الافتراضي:** ملاءمة العرض، أو ملاءمة الصفحة، أو الحجم الفعلي.
- **فتح مجلد السجلات:** يفيد في تشخيص المشكلات.

## الخصوصية والأمان

- يعمل التطبيق دون اتصال بالإنترنت، ولا يرسل أي بيانات.
- لا يعدّل ملفاتك الأصلية أبدًا.
- لا يشغّل وحدات الماكرو ولا البرامج النصية الموجودة في المستندات.
- تُحفظ نسخ PDF من مستندات Office التي عاينتها على جهازك فقط، في `%LOCALAPPDATA%\Lamha\cache`، وتُحذف عند إلغاء التثبيت.
- لا يسجّل أسماء ملفاتك أو محتواها في السجلات.

## حل المشكلات

**لا يحدث شيء عند ضغط المسافة:**
- تأكد من ظهور أيقونة لمحة بجوار الساعة ومن تفعيل التكامل مع المستكشف.
- انقر ملفًا في قائمة الملفات أولًا. لا يعمل المفتاح أثناء الكتابة في شريط العنوان أو مربع البحث أو عند إعادة تسمية ملف، وهذا مقصود.
- إذا كان المستكشف يعمل بصلاحيات المسؤول، فلن يتمكن التطبيق من التعامل معه.

**تظهر رسالة «لا يمكن معاينة هذا النوع من الملفات»:** الملف المحدد غير مدعوم أو أنه مجلد.

**يبدو خط مستند Office مختلفًا عن الأصل:** إذا لم يكن الخط مثبتًا على جهازك أو مضمّنًا في المستند، يُستخدم خط بديل قريب منه.

## إلغاء التثبيت

افتح **الإعدادات ← التطبيقات ← التطبيقات المثبتة**، واختر **لمحة**، ثم **إلغاء التثبيت**. يُحذف التطبيق وإعداداته وسجلاته وملفاته المؤقتة، ويُزال تشغيله التلقائي.
